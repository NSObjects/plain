Plain 是一个面向开发者的 Astro 博客主题，适合记录工程经验、技术方案和长期积累的思考。

## 为什么做一个简洁的主题？

博客最重要的是内容。Plain 尽量减少不必要的装饰，为文章、代码和图表提供清晰的阅读空间。

## 让代码成为内容的一部分

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Plain!")
}
```

## 开始写作

在 `src/content/posts/` 目录中创建 Markdown 文件，填写标题、摘要、发布日期等信息，就能发布自己的第一篇文章。

> 好的阅读体验，应当让读者专注于文字本身。
